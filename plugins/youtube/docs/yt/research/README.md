# Ricerca di base — non distribuita

Il knowledge pack (`../knowledge/01…13`) riassume la ricerca da cui nasce il plugin, con fonti, date di verifica ed etichette di evidenza: è la versione vincolante. Le sigle che compaiono nei file («SYNTHESIS §…», «F4 §…», «V2 §…», «X1», «I1») indicano la provenienza di un'affermazione in un archivio di lavoro che non fa parte del plugin: non sono file da aprire.
Se un dettaglio serve a tutti, va portato nel knowledge pack con una pull request (`CONTRIBUTING.md`), con la sua fonte pubblica.
